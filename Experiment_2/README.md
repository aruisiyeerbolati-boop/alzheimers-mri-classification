# Experiment 2 – Alzheimer's MRI Classification

## 1. Overview

Experiment 2 compares three machine learning methods for Alzheimer's disease classification using MRI images from an OASIS-derived dataset.

The three methods are:

- Convolutional Neural Network (CNN)
- Support Vector Machine (Pixel SVM)
- Hybrid model (CNN feature extraction combined with SVM)

The experiment evaluates the models using two input conditions: original MRI images (Raw) and contrast-enhanced images (CLAHE).

## 2. Dataset

The experiment uses 5,000 MRI images from 342 subjects.

| Dataset split | Number of images |
|---|---:|
| Training | 3,476 |
| Validation | 637 |
| Testing | 887 |
| Total | 5,000 |

The original MRI dataset contains four categories: Non-Demented, Very Mild Demented, Mild Demented and Moderate Demented.

For binary classification, the dementia categories are grouped into the Demented class.

The dataset uses a subject-disjoint split to prevent images from the same subject appearing across training, validation and testing sets.

The test set comes from the same dataset source and is not an independent external clinical cohort.

## 3. Models and Methods

**CNN:** Learns image features directly from MRI images.

**Pixel SVM:** Uses image-based features for classification with a Support Vector Machine.

**Hybrid CNN–SVM:** Uses features extracted by a CNN and applies SVM for classification.

Both Raw and CLAHE-processed images are considered in the evaluation.

## 4. Results and Evaluation

The experiment compares model performance using classification metrics, including Accuracy, F1-score and AUC.

Saved models and evaluation figures are located in the `results/` directory.

Additional recovered evaluation records are available in the `recovered_evaluation/` directory. These records were generated by re-evaluating the saved Experiment 2 models and were cross-checked against the available model and dataset records.

### Re-evaluation Accuracy

| Model | Raw | CLAHE |
|---|---:|---:|
| CNN | 76.78% | 55.58% |
| Pixel SVM | 44.98% | 43.63% |
| Hybrid CNN–SVM | 74.30% | 61.89% |

These values are from the saved-model re-evaluation, not a reconstruction of the original training logs.

The test set is class-imbalanced. Therefore, Accuracy should be interpreted alongside other evaluation metrics rather than used alone.

## 6. Verification Status and Limitations

The recovered evaluation records have been checked for consistency with the saved model files and the available dataset manifest.

However, some original Experiment 2 training records, including complete epoch logs and original configuration information, are unavailable.

Therefore, the saved-model re-evaluation results have been cross-checked, but the original full training verification remains incomplete.

The recovered files should be treated as supplementary evidence rather than replacements for the missing original training records.

## 7. Research Context

Experiment 2 is part of the research project:

**Widely Used Machine Learning Methods for Alzheimer's MRI Classification**

The research compares CNN, SVM and hybrid approaches across three experiments to examine their classification performance under different experimental settings.
