# Experiment 3

Alzheimer's MRI Classification – Parameter Alignment Experiment.

This experiment uses 5,000 OASIS MRI images with a subject-disjoint split of 3,476 training, 637 validation, and 887 test images.

Models: CNN, Pixel SVM, and CNN–SVM Hybrid.

The evaluation uses a held-out test set from the same OASIS dataset, not an independent external cohort.
